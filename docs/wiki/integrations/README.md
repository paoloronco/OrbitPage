# Integrations

Connect external content and services to your self-hosted page.

| Task | Guide |
| --- | --- |
| Add WhatsApp, GitHub, video/audio players, Calendly, Typeform or Google Forms | [External modules](./external-modules.md) |
| Configure iubenda, CookieYes, Cookiebot, OneTrust or a custom CMP | [Consent management](./consent-management.md) |
| Connect an SMTP server for newsletters | [Newsletters](../dashboard/sections/newsletters.md) |
| Configure the page AI assistant | [AI assistant](../ai-assistant.md) |
| Automate the self-hosted application | [API boundary](../development/api.md) |

The managed service has separate guides for [Stripe Shop payments](https://orbitpage.com/en-US/docs/stripe) and [Cal.com paid-service bookings](https://orbitpage.com/en-US/docs/cal-com). Native Shop payments and booking synchronization are not available in the self-hosted edition. You can add an external payment or Cal.com booking URL as a normal **Link** block.
