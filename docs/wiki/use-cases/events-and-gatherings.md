# Create an event or invitation page

Create an OrbitPage for an event with its date, location, programme and response link. Check the public details before sharing invitations.

## Build and publish

A birthday, wedding, reunion or local meetup can generate a long chain of messages. Give guests one page with the details they need and update it when the plans change.

1. Set the event identity in **Page** and put the date, time and place near the top of **Content**.
2. Add event details, a programme and a map or directions where useful.
3. Add a response action linked to the RSVP, registration or booking service you use. Keep private responses in that service.
4. Save and check the public page before sharing its link or printing a QR code. Update the same page when plans change.

<a id="details"></a>

## Put the date, time and place first

Add the event name, the date and the place guests should arrive. Include directions and any practical arrival information. A countdown can help draw attention to the next date, while a short programme explains what happens when.

<a id="response"></a>

## Link to the form or booking tool you already use

Put a clear response action beside the event details. Link to an RSVP form, a registration page or a booking service. Responses stay in that tool; OrbitPage gives guests a useful place to find it.

<a id="updates"></a>

## Correct the page instead of resending every detail

Change the time, arrival instructions or programme on the existing page and publish the update. Share its address in the invitation or use a QR code on printed material. Guests can return to the same place for the current plans.

<a id="privacy"></a>

## Keep personal guest information in your response tool

A published page is public. Do not publish a guest list, private responses or a home address you want to keep confidential. Share sensitive details directly with guests or through your chosen invitation service.
