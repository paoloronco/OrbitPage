# Build a page for your creative work

Build a creator page with your current release, selected work, contact and optional offers. Review the public page before sharing a campaign.

Part of the [documentation index](../README.md), under **Examples and use cases**.

## Build and publish

A visitor should quickly understand who you are, what you are working on and where to go next. OrbitPage AI can prepare page edits; Shop can sell selected files or sessions.

1. Set your identity and main creative focus in **Page**.
2. Feature the current release, video, exhibition or project first in **Content**, followed by selected work and contact.
3. Add a newsletter or booking route when useful. Follow the Shop setup guide before offering a digital file or paid session.
4. Save, check media and destinations on the public page, and use a campaign link when you need to distinguish sources.

<a id="problem"></a>

## Social profiles scatter context across platforms

A visitor may discover one post without knowing the current project, preferred channel or contact route. A single public destination provides that missing frame without becoming a full portfolio rebuild.

<a id="structure"></a>

## Lead with identity, current work and one meaningful action

Use a short profile, compact social row, featured release or project, selected links and a contact action. Put archive material behind a dedicated page rather than letting old work crowd the main path.

- Profile and compact social links
- Current release, video or event
- Selected work, services or Shop
- Contact, booking or newsletter

<a id="ai"></a>

## Turn a launch brief into page changes you can review

Ask OrbitPage AI to tighten a biography, introduce a new release, reorganize standard blocks or adapt the visual theme. It prepares a proposal for the open page; the creator reviews it before anything is applied.

Use it to reduce blank-page work, not to invent credits, availability or claims that have not been checked.

<a id="shop"></a>

## Sell the small number of offers that belong beside the work

Digital editions, guides, presets, files and paid creative sessions can live in the same branded destination. Stripe handles payment while OrbitPage protects digital delivery or passes the buyer into the service booking path.

A focused catalog usually performs a clearer job than importing every item from a larger store.

<a id="ownership"></a>

<a id="use-the-hosted-page-now-keep-a-path-to-your-own-domain"></a>

## Choose a stable public address

Use the same public address in video credits, printed work and partnerships. A domain you control lets you retain that identity when hosting changes. Review the [public-address settings](../dashboard/sections/publishing.md#public-address) before sharing; updating content at the same URL keeps existing links useful.

<a id="measure"></a>

## Compare projects and campaigns, not follower counts

Track which featured action earns attention, which source sends useful visitors and whether a campaign drives the intended click. Keep page analytics separate from unrelated marketing traffic.

## Check the result

- Open the featured release and contact action on a phone.
- Test embedded media after accepting and rejecting its consent category.
- If selling, complete the [Shop test checklist](../integrations/stripe.md#test-checklist) before sharing a purchase link.
