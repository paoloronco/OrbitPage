# Create a page for a group or shared project

Create an OrbitPage for a group or project with its next meeting, shared resources and joining details, while keeping private documents protected.

Part of the [documentation index](../README.md), under **Examples and use cases**.

## Build and publish

A book club, sports group, volunteer project or band can need a page without needing a marketing site. Keep the next date, useful links and a way to join together.

1. Set the group name and purpose in **Page**, using only images and information you may publish.
2. Put the next meeting and a joining or contact action near the top of **Content**.
3. Group useful resources and check access permissions in the services that store private documents.
4. Save, review the public page and share one address. Give collaborators individual accounts and appropriate access when needed.

<a id="about"></a>

## Explain what brings you together

Add the group name and a short description of what you do. Include a photo or a few examples of the project, with permission from the people involved. Let a new visitor understand whether the group is open to them.

<a id="meet"></a>

## Make the next meeting easy to find

Show the date, place and meeting details near the top. Add a contact or registration link for someone who wants to join. Update the page after each meeting so it does not keep advertising an event that has already passed.

<a id="resources"></a>

## Keep the resources people ask for close by

Link to a reading list, rehearsal recording, project repository or shared document. Keep access permissions in the service that stores those resources: a link on a public page should not expose a private group document.

<a id="maintain"></a>

## Share one address and update it as the project grows

Use the page address in messages, posters or a QR code. Start with a single editor; if several people need to maintain it, give collaborators individual accounts and appropriate permissions.

## Check the result

- Check joining instructions and the next meeting without signing in.
- Confirm that private documents still require authorization in their source service.
- If others edit the page, verify their individual accounts and permissions with the [Team guide](../dashboard/sections/account-and-team.md).
