# Create a venue or club page

Build a venue page with upcoming events, booking links, directions and a readable menu. Review the programme and publish current information.

## Build and publish

For a venue, relevance changes by date. The page must surface what is happening now, preserve stable routes for guests and make commercial offers distinct from ticketing.

1. Set the venue identity in **Page** and introduce the kind of programme visitors can expect.
2. Add the next events with dates, times and the correct booking or ticket destinations.
3. Add directions, practical arrival details, media and a structured menu when useful.
4. Save and check the public page on a phone. Review expired dates and external booking destinations whenever the programme changes.

<a id="problem"></a>

## An old event is worse than a missing one

Visitors arriving from social media need the next relevant date, not an archive of expired promotions. Event blocks and scheduling help the page change with the venue's calendar.

<a id="structure"></a>

## Lead with booking, then prove what the night is

Use table or ticket booking first, followed by the current event, selected media, location and contact. Compact social links keep the relationship with existing channels without forcing visitors to search them for basic details.

- Tables, tickets or guest list
- Next event with date and countdown
- Current visuals or video
- Map, contact and house information

<a id="ai"></a>

## Prepare the next campaign without losing the stable structure

Ask AI to replace last week's emphasis, rewrite the opening copy, add or reorder a standard event block and adjust the theme for a new campaign. Review the exact proposal before applying it to the open page.

The team still owns dates, prices, line-ups and entry information.

<a id="shop"></a>

## Package private hire and paid experiences beside the calendar

Private-event consultations, workshops or other bookable venue services can use payment, intake questions and a booking route. Keep high-volume ticket inventory, scanning and access control in the specialist ticketing system, then link it prominently from OrbitPage.

<a id="campaigns"></a>

## Use a stable page with trackable event routes

A stable public address is easier to print and remember than a new link for every night. Campaign parameters and analytics can still distinguish promoters, posts and events.

<a id="operations"></a>

## Assign editing without sharing the owner's password

An administrator can manage the workspace while an editor updates current content and an analytics viewer reads performance. Team access remains visible and removable.
