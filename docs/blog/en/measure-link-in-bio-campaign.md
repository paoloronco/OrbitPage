# What to measure after a link-in-bio campaign

Read visits, sources and action clicks after a social campaign without confusing page engagement with bookings, enquiries or sales.

OrbitPage · 2026-09-17 · English

[Read on OrbitPage](<https://orbitpage.com/en-US/blog/measure-link-in-bio-campaign>) · [Browse the archive](<https://github.com/paoloronco/OrbitPage/tree/main/docs/blog>)

A campaign can bring more visitors without bringing the right visitors. The useful question is not simply whether a number went up; it is whether people arriving from a particular message found the action that message promised. A small measurement routine can answer that without a giant dashboard.

<a id="question"></a>

## Write the campaign's intended action before reading the report.

A release might aim for listens, a venue post for reservations and a professional announcement for enquiries. Name that destination before checking the numbers so every metric has a job.

Keep the public page stable enough to compare campaigns. If the main action, copy and offer all change mid-run, the result is harder to interpret.

<a id="sources"></a>

## Tag campaign links consistently and compare like with like.

Use a consistent campaign label for each channel or creative when you can control the shared URL. Source and referrer data can be incomplete, especially in apps and private browsing, so treat them as directional rather than perfect attribution.

Compare visits and visitors in the same period, then ask which source reached the intended action. A large source can underperform a smaller but better-matched audience.

<a id="actions"></a>

## A click is a handoff, not the final outcome.

OrbitPage can show page visits and outbound action clicks. The booking tool, mailbox or checkout system owns the later confirmation; reconcile those outcomes separately instead of calling every click a sale.

Look at the main action and a small number of meaningful alternatives. A visitor who opens directions instead of reservations may still be behaving sensibly for a local venue.

<a id="next-test"></a>

## Change one confusing part, then measure again.

If visitors arrive but ignore the promised action, examine the first screen, label and supporting context. If they click but do not complete the next step, inspect the destination rather than endlessly rewriting the page.

Record the date of each important page edit. Even modest traffic can teach something when changes are specific and the final business outcome is checked where it actually happens.
