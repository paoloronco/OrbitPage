# Die Buchungsseite eines Porträtfotografen aktuell halten

Eine praktische Routine, um Links zu Porträtsitzungen aktuell zu halten, veraltete Angebote zurückzuziehen, die Zuständigkeit für die Seite festzulegen und den Live-Anfrageweg zu überprüfen.

![Aus einem abgelaufenen Angebot einen funktionierenden Anfrageweg machen](<https://orbitpage.com/api/blog/illustrations/portrait-photographer-booking-page-maintenance?v=2&locale=de>)

Eine Porträtseite kann professionell wirken und Besucher dennoch unauffällig zu einem veralteten Buchungsformular leiten oder für Sitzungen werben, die bereits vorbei sind. Eine einfache Wartungsroutine hält Angebot, Seite und Ziel aufeinander abgestimmt, ohne dass eine vollständige Neugestaltung nötig ist.

<a id="section-1"></a>

## Die Seite und ihre Ziele erfassen

Geben Sie jedem Link eine klare Aufgabe für Besucher: ausgewählte Porträts ansehen, mehr über Ihre Sitzungen erfahren, eine Frage stellen oder eine Buchung anfragen. Verwenden Sie Bezeichnungen, die die Aktion erklären, etwa „Nach einer Porträtsitzung fragen“ statt des vagen „Kontakt“. Entfernen Sie Links, die niemandem mehr dabei helfen, einen passenden nächsten Schritt zu machen.

Halten Sie fest, wo die einzelnen Informationen liegen und wer sie ändern kann. Sie bestimmen den Wortlaut und die Links auf Ihrer öffentlichen Seite, während ein Buchungskalender oder ein Anfrageformular möglicherweise über einen separaten Dienst verwaltet wird. Wenn Sie die Seite aktualisieren, werden diese externen Ziele nicht automatisch mit aktualisiert.

Bestimmen Sie eine für die Pflege zuständige Person, auch wenn Sie das selbst sind, und halten Sie die Ziele und ihre jeweiligen Verantwortlichen in einer kurzen Übergabenotiz fest. Mit OrbitPage können Sie Seitendetails bearbeiten und Inhaltsblöcke organisieren. Wann diese überprüft werden und ob externe Dienste kontrolliert werden, liegt jedoch in Ihrer Verantwortung.

<a id="section-2"></a>

## Eine zu Ihrer Arbeit passende Routine für die Überprüfung entwickeln

Richten Sie eine regelmäßige Erinnerung ein, deren Häufigkeit sich danach richtet, wie oft sich Ihre Verfügbarkeit, die Orte für Sitzungen oder Ihre Angebote ändern. Überprüfen Sie alles früher, sobald sich eines dieser Details ändert. Öffnen Sie die veröffentlichte Seite aus der Sicht eines Besuchers und folgen Sie den wichtigen Links bis zu ihren Zielen – verlassen Sie sich nicht nur auf die Bearbeitungsansicht.

Prüfen Sie auf einem Smartphone, ob Besucher Ihre Porträtarbeiten schnell erkennen und den vorgesehenen nächsten Schritt finden können. Vergewissern Sie sich, dass die ausgewählten Bilder geladen werden und die Bildunterschriften die Arbeiten noch korrekt beschreiben. Diese Prüfungen führen Sie selbst durch; der Seiteneditor bestätigt nicht, ob ein externes Formular oder ein Buchungskalender aktuell ist.

Wenn Sie den Browser-Titel oder die Suchbeschreibung in den Seiteneinstellungen von OrbitPage bearbeiten, vergleichen Sie diese mit der Live-Seite. Suchmaschinen und Messaging-Apps zeigen möglicherweise eine Zeit lang noch ältere Vorschauen an. Eine gespeicherte Änderung bedeutet daher nicht, dass sie überall sofort aktualisiert wird.

-   Prüfen Sie, ob bei einem Angebot oder einer Sitzungsbeschreibung ein Enddatum angegeben ist, das bereits verstrichen ist.
-   Bestätigen Sie, wer namentlich für die nächste Überprüfung der Seite und ihrer Ziele zuständig ist.
-   Stellen Sie sicher, dass die Übergabenotiz vertraulich gespeichert ist, falls sie Kontodaten enthält.

## Hypothetisches Beispiel: Ein abgelaufenes Frühlingsangebot ersetzen

Hypothetisches Beispiel: Mira, eine fiktive freiberufliche Fotografin, hat eine öffentliche Seite, auf der sie ein Frühlingsangebot für Porträts bewirbt. Das Angebot ist abgelaufen, aber die Schaltfläche öffnet weiterhin ein Formular mit dem Titel „Anfrage für eine Frühlings-Minisitzung“. Diese Diskrepanz könnte bei Besuchern den Eindruck erwecken, dass solche Sitzungen noch verfügbar sind.

Mira entfernt die abgelaufene Werbung und verwendet einen aktuellen, nicht an ein bestimmtes Datum gebundenen Wortlaut: „Porträtsitzungen werden auf Anfrage vereinbart. Erzählen Sie mir, welche Art von Sitzung Ihnen vorschwebt, und ich antworte mit meiner aktuellen Verfügbarkeit.“ Sie ändert die Schaltfläche erst dann in „Nach einer Porträtsitzung fragen“, wenn sie bestätigt hat, dass das Ersatzformular bereit ist.

Da das Formular extern ist, öffnet Mira es separat und prüft, ob Titel oder Fragen Verweise auf Frühlingstermine enthalten. Anschließend besucht sie die öffentliche Seite und folgt der Schaltfläche, um zu bestätigen, dass sie zum vorgesehenen Formular führt. Solange sie keine konkreten Termine bestätigt hat, vermeidet sie den Eindruck, Besucher könnten diese sofort buchen.

Dabei gibt es einen Zielkonflikt: Ein allgemeiner Anfrageweg kann länger aktuell bleiben, aber Besucher müssen erst nachfragen, bevor sie wissen, wie es um die Verfügbarkeit steht. Ein direkter Kalender macht den nächsten Schritt klarer, wenn Termine und Sitzungsoptionen aktuell gehalten werden.

<a id="section-4"></a>

## Das nächste Update überschaubar halten

Halten Sie für jedes wichtige Ziel kurz fest, wozu es dient und wer es ändern kann. Kennzeichnen Sie, welche Details auf der öffentlichen Seite stehen und welche zu einem externen Dienst gehören. Diese kleine Unterscheidung hilft zu vermeiden, dass nach einer Seitenänderung ein veraltetes Formular oder ein alter Kalender unverändert bleibt.

Überlegen Sie vor einer größeren Änderung, ob Sie eine Sicherung benötigen. Der reine Inhalts-Export von OrbitPage umfasst die Blockliste der Hauptseite; Profile, Themes, Menüs, Unterseiten, Datenschutzeinstellungen, Konten oder Inhalte hochgeladener Dateien lassen sich damit nicht wiederherstellen. Eine umfassendere Sicherung kann ausgewählte Bereiche enthalten; referenzierte Medien müssen möglicherweise separat einbezogen werden. Bewahren Sie Sicherungen vertraulich auf, da sie unveröffentlichte Inhalte und Konfigurationen enthalten können.

Öffnen Sie jetzt Ihre veröffentlichte Seite, tippen Sie auf die Hauptschaltfläche für Porträtsitzungen und bestätigen Sie, dass das Ziel zu den Sitzungen passt, die Sie derzeit anbieten.
