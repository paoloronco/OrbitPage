# ポートレート写真家の予約ページを最新に保つ

ポートレート撮影のリンクを最新に保ち、古いオファーを終了し、ページの担当者を決め、問い合わせの導線が正しく機能するか確認するための実践的なルーティンです。

[Read on OrbitPage](<https://orbitpage.com/ja-JP/blog/portrait-photographer-booking-page-maintenance>) · [Browse the archive](<https://github.com/paoloronco/OrbitPage/tree/main/docs/blog>)

![終了したオファーを、機能する問い合わせの導線に変える](<https://orbitpage.com/api/blog/illustrations/portrait-photographer-booking-page-maintenance?v=2&locale=ja>)

ポートレート撮影のページは洗練されて見えても、訪問者を古い予約フォームにひそかに誘導していたり、終了した撮影プランを宣伝し続けていたりすることがあります。簡単なメンテナンスのルーティンを設ければ、大がかりなデザイン変更をしなくても、オファー、ページ、リンク先の内容を一致させておけます。

<a id="section-1"></a>

## ページとリンク先を整理する

すべてのリンクに、訪問者がそこで行うことを明確に示しましょう。選りすぐりのポートレートを見る、撮影プランについて知る、質問する、予約を申し込む、といった具合です。「お問い合わせ」のような曖昧な表現ではなく、「ポートレート撮影について相談する」のように、操作内容がわかるラベルを使いましょう。次に取るべき行動に関係のないリンクは削除します。

各情報がどこにあり、誰が変更できるのかを記録しておきましょう。公開ページ上の文章やリンクは自分で管理できますが、予約カレンダーや問い合わせフォームは別のサービスで管理されている場合があります。ページを更新しても、外部のリンク先が自動的に更新されるわけではありません。

担当者を決めましょう。自分自身でもかまいません。リンク先とその管理者を記した簡潔な引き継ぎメモも用意しておきます。OrbitPageではページの詳細を編集し、コンテンツブロックを整理できます。見直しの時期を決めることや、外部サービスを確認することは手作業で行う必要があります。

<a id="section-2"></a>

## 仕事に合った見直しのルーティンを作る

空き状況、撮影場所、オファーがどのくらいの頻度で変わるかに応じて、定期的なリマインダーを設定します。いずれかの内容が変わったら、その都度早めに見直しましょう。編集画面だけでなく、訪問者の立場で公開ページを開き、重要なリンクをたどってリンク先まで確認します。

スマートフォンほどの画面サイズで、訪問者があなたのポートレート作品をすぐに見つけ、意図した次の操作に進めるか確認しましょう。選んだ画像が読み込まれ、キャプションが今も作品を正確に説明していることも確かめます。これらは自分で行う確認事項です。ページエディターは、外部フォームや予約カレンダーが最新かどうかを確認しません。

OrbitPageのページ設定でブラウザーのタイトルや検索結果の説明文を編集した場合は、公開ページと照らし合わせて確認しましょう。検索エンジンやメッセージアプリには古いプレビューがしばらく表示されることがあるため、変更を保存しても、すべての場所でただちに更新されるとは限りません。

-   オファーや撮影プランの説明に、すでに過ぎた終了日が含まれていないか確認します。
-   次回のページとリンク先の確認を担当する人を明確にします。
-   引き継ぎメモにアカウント情報が含まれる場合は、非公開の場所に保管してください。

![古いオファーを見つける → ページを更新する → フォームを確認する → ボタンをたどる](<https://orbitpage.com/api/blog/illustrations/portrait-photographer-booking-page-maintenance?variant=steps&v=2&locale=ja>)

終了したオファーを、機能する問い合わせの導線に変える。説明用の例です。

<a id="section-3"></a>

## 仮定の例：終了した春のオファーを差し替える

仮定の例：架空の個人写真家、ミラは、春のポートレート撮影プランを宣伝する公開ページを持っています。オファーは終了していますが、ボタンを押すと「春のミニ撮影の申し込み」というタイトルのフォームが開きます。この不一致によって、訪問者はまだその撮影を予約できると思い込むおそれがあります。

ミラは終了した宣伝を削除し、日付を限定しない最新の文言に差し替えます。「ポートレート撮影はお問い合わせに応じて調整します。ご希望の撮影内容をお知らせください。現在の空き状況を返信します。」差し替え後のフォームが準備できていることを確認してから、ボタンを「ポートレート撮影について相談する」に変更します。

フォームは外部サービス上にあるため、ミラはフォームを別途開き、タイトルや質問に春の日付への言及がないか確認します。それから公開ページにアクセスし、ボタンをたどって意図したフォームに移動することを確かめます。具体的な日程を確認していない場合は、訪問者がすぐにその日程を予約できるかのような表現は避けます。

ここにはトレードオフがあります。一般的な問い合わせ窓口なら、より長く正確な状態を保てますが、訪問者は空き状況を知る前に問い合わせる必要があります。日程と撮影オプションを最新に保てるなら、直接予約できるカレンダーのほうが次の手順を明確にできます。

<a id="section-4"></a>

## 次回の更新を無理なく進める

重要なリンク先ごとに、その用途と変更できる人を簡潔に記録しておきましょう。公開ページに表示される情報と、外部サービスにある情報を区別して記します。この小さな区別によって、ページを編集しても古いフォームやカレンダーがそのまま残る事態を防ぎやすくなります。

大幅な変更を行う前に、バックアップが必要か検討しましょう。OrbitPageのコンテンツのみのエクスポートに含まれるのは、メインページのブロック一覧です。プロフィール、テーマ、メニュー、サブページ、プライバシー設定、アカウント、アップロードしたファイルの内容は復元されません。より広範なバックアップには選択したセクションを含められます。また、参照されているメディアは別途含める必要がある場合があります。バックアップには未公開のコンテンツや設定が含まれることがあるため、非公開の場所に保管してください。

それでは公開ページを開き、メインのポートレート撮影ボタンをタップして、現在提供している撮影プランに合ったリンク先が開くことを確認しましょう。
